# online-food-delivery
A DevOps-based online food delivery application project focused on automating software development, testing, and deployment using Git and CI/CD practices.
# Online Food Delivery Application

## Overview
This project demonstrates the implementation of DevOps practices for an online food delivery application.

## Objectives
- Improve collaboration between development, testing, and operations teams.
- Automate software build and testing.
- Design a CI/CD pipeline for faster deployment.
- Reduce deployment time from 3 days to 2 hours.
- Minimize manual errors and deployment failures.

## Tools
- Git and GitHub
- Jenkins or GitHub Actions
- Maven
- JUnit
- Docker

## Project Goal
To improve software delivery speed, reliability, and application quality using DevOps practices.
